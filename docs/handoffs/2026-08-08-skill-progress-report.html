01What it does

Give it a description of a kind of person — “pediatric anesthesiologists within 15 miles of Myrtle Beach”, “licensed roofers near Tampa” — and it finds them in public registries, resolves what contact detail genuinely exists, and writes a CSV with a source and a confidence label on every field.

The load-bearing behaviour is refusal. With no known-good address for a domain it emits nothing and says so. That property is enforced by a deterministic script, not by the model choosing to be careful on a given run.

Design constraint

Shipped scripts make no network calls at all. The Claude apps sandbox has no outbound access, so a script that fetches is a script that silently fails there. The agent fetches with its own tools; the script transforms.

The email ceiling is a property of the population, not the tooling

Hospital anesthesia is contracted out. A federal filing named the groups: Atlantic Coast Anesthesia Services PC staffs the largest facility in the ring with 258 members — and every candidate domain for it has no DNS record at all. No A record, no MX, no first-party website. Those people are not reachable by email because their employer has no mail domain in existence.

Where a population does publish, the yield inverts: one academic medical centre produced 78 addresses where a comparable community roster produced 5.

03How it got here

Aug 6

Four benchmark rounds, two skills, head to head

A second skill was generated independently against the same brief so each could absorb what the other did better. Every ported mechanism got a test written before the port, failing against the pre-port version — that failing run is the evidence the port was needed.

Aug 7

Universality: the skill had silted into a healthcare skill

Measured at 3.5:1 clinical-to-general vocabulary in the always-read files. Rewritten around a population-class method — Licensed, Public payroll, Entity principal, Credentialed, Association, Privately employed — which decides whether a roster can be enumerated at all. Clinical detail moved to a pack that loads only on match.

Aug 7

Proof: pointed at licensed roofers near Tampa

865 found in a 25-mile ring, zero web searches, from a 48 MB state file reached by navigating rather than searching. It broke in four places, and each break became a test.

Aug 8

Validated against the official spec, then mined Anthropic’s own repos

Every frontmatter rule had been inferred from failed uploads. The published spec and its reference validator confirmed the inference was right. Anthropic’s healthcare plugin then supplied three mechanisms: catalog resolution, a taxonomy of how government sites resist you, and a registry status field we had never read.

Aug 8

Cracked the contractor groups

A 537 MB federal reassignment file, 3,373,759 rows, linked people to the groups they bill through. Employer coverage went 0% to 74%, three blocking groups were enumerated outright, and 453 people the registry sweep had missed surfaced — 35 of them inside the 15-mile ring.

04Corrections

Roughly a third of the recommendations made during this work failed on contact with reality. Each one is recorded because the retraction is more useful than the original claim.

Shared mail infrastructure does not license an email pattern

Two domains sharing an MX host with the same tenant id are one mail system, so a pattern propagates between them.

Tested against a third domain and collapsed: MUSC, a separate institution, sits on the same Proofpoint pod as Tidelands. The hex string is a pod, not a customer. It looked discriminating only because the first sample was two domains that genuinely were related — the same two-sample error this skill warns about everywhere else. Would have fabricated addresses.

The docs and the code disagreed about mixed domains

Documentation said “correct output for a mixed domain is zero addresses” from the beginning. The code downgraded the confidence label and emitted anyway. The doc was right — competing evidence is a coin flip at roughly 2/3 accuracy, which is 33 bounces per 100 against a ~2% ceiling. Both implementations now resolve nobody.

Merge collapsed 107 distinct people into one another

The dedupe key was name plus employer, and a licence register has no employer — so it degenerated to name alone. Two different people with the same name became one row holding one man’s address and another’s licence number. Found only by pointing the skill at a non-clinical population.

The benchmark was scoring front desks as contact

Reachability counted any phone at 25% of the score. Of 680 people with a number, zero were direct dials. Now weighted by channel — and the first version of that fix contained a perverse incentive that rewarded runs for omitting their labels.

Recommendations that did not survive testing

South Carolina business filings (CAPTCHA-gated), crt.sh (502), DuckDuckGo’s HTML endpoint (serves a CAPTCHA), US mobile-vs-landline detection (the numbering plan does not distinguish them), and a LinkedIn scorer that confidently accepted two namesakes at full marks.

05The commercial question, settled

Whether free public sourcing can reproduce what Clay and Apollo sell. It can reproduce most of it, and provably not the part everyone asks for first.

Mobile numbers cannot be derived, only obtained. An email is a deterministic function of a name and a domain, which is why every vendor ships a pattern generator. A mobile is a random ten-digit string carrying no information about its owner, so none of them ships anything analogous. ZoomInfo files its contributory network as a material risk factor in its annual report; Apollo’s terms describe the barter outright and price a phone at eight times an email.

The one vendor that genuinely crawls the open web returned the most numbers in an independent call-verified benchmark and scored 11.5% good, 51.5% junk.

Where this wins instead

A commercial tool returned two pediatric anesthesiologists within 50 miles of Myrtle Beach. The federal registry enumerated 72 anesthesiologists. These tools are not weak because they cost money — they have fixed connectors and sample the population. Registration is mandatory, so the register has everyone.

The same shape holds for owner-operators: a federal carrier census carries 1,874,212 verified mobile numbers attached to named officers, free, because contributory networks are fed by office workers’ inboxes and the person who owns one truck is in nobody’s address book.
